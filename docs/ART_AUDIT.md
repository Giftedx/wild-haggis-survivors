# Art Audit — Wild Haggis Survivors

Living doc. One section per category. Within each section, per-sprite notes with priority flag:

- **P0** — broken / wrong / misleading silhouette. Fix immediately.
- **P1** — weak; reads but doesn't match the bar set by the best sprites.
- **P2** — polish opportunity; already fine, could be better.
- **P3** — ok / bar-setting; leave alone.

Generated by reviewing `?export=sprites` PNG + source code in `src/scenes/BootScene.ts` (legacy sprites) and the Phase-0 drawers in `src/animation/frameDrawers/` + `src/entities/haggisComposition/drawers/`.
