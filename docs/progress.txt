[2026-04-13] Phase 3 — bug-hunt sweep (2 real bugs, fixed)

User asked for find-and-fix loop across the codebase. Dispatched
parallel Explore agents over scenes/systems/entities/core+data,
verified each finding myself before fixing. Most agent claims were
false alarms (gratuitous defensive guards, type-cast hand-wringing,
or reading the code wrong). Two real bugs surfaced and shipped:

1. 9c53ced fix(projectile): pierce/bounce no longer double-hit same
   enemy. shouldSkipHit's "recycled pool slot" branch deleted the
   hit record whenever enemy.active was true — and real enemies
   ARE active while alive, so every overlap frame after the first
   counted as a fresh hit. The unreachable `else` branch was the
   only path the test exercised (mock enemy was `{}`, no `active`
   prop). Strengthened the test with `active: true` mocks plus a
   per-frame piercing regression case.

2. f17a0b1 fix(enemy): chemical explosion fires regardless of
   burn/poison order. Synergy check lived only inside applyPoison;
   "poison first, burn second" silently dropped the explosion.
   Production impact was masked by Scotch Mist re-applying poison
   every 500ms — but a future single-shot poison weapon would
   have inherited the broken contract. Extracted to a private
   maybeFireChemicalExplosion() helper called from both apply paths.
